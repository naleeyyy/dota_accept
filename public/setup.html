Setup

About 5 minutes. You need a Windows PC and a phone. Nothing to install.

  1. Download the client on your PC

    Download client.zip

    Right-click the zip, choose Extract All, and open the extracted client folder. Keep both files together:

    • enter-client.ps1 is the client itself
    • start.bat starts it

  2. Start it

    Double-click start.bat. A window opens showing your Client ID and a link.

    If Windows SmartScreen warns you, click More info → Run anyway. Leave the window open while you play; minimizing it is fine.

  3. Connect your phone

    Open the link from the client window on your phone, or open this site and paste the Client ID into the box. The dot should turn green and say Client online.

    Your Client ID is your password. Anyone with it can press Enter on your PC, so don't share it. To change it, delete client-id.txt in the client folder and restart the client.

  4. Turn on notifications

    • Android / desktop: tap Enable notifications on the main page and allow them.
    • iPhone: first tap Share → Add to Home Screen, open Remote Enter from the home screen, then tap Enable notifications. iPhones only allow notifications from home-screen apps.

  5. Teach it the Accept button

    You only do this once. The next time a match pops while you're at the PC:

    • Hover your mouse over the ACCEPT button and press F8.
    • Move the mouse off the button within 2 seconds, so the saved picture doesn't include the hover highlight.
    • You'll hear a beep. Accept the match as normal.

    The client saves calibration.png next to the script. Open it and check it shows the Accept button. The client only looks at that spot on your screen; it doesn't read any game files.

  6. Queue and walk away

    When a match is found you'll get a Match ready! notification.

    • Android: tap Accept (press Enter) right on the notification.
    • iPhone: tap the notification, then the big Press Enter button.

    Enter goes to whichever window is in front, so leave Dota focused.

Troubleshooting

Enter doesn't do anything in Dota

Switch Dota to borderless windowed in the video settings; exclusive fullscreen can ignore simulated keys. If Dota runs as administrator, right-click start.bat and choose Run as administrator too.

No notification when a match pops

Dota must be visible on screen, not minimized. If you changed resolution, window size or monitor since setup, press F8 on the button again.

Still nothing? Open enter-client.ps1 in Notepad, set $ShowScores = $true and restart. It prints a score every second: it should be close to 1 while the Accept button is showing. If it peaks lower, reduce $Threshold (default 0.90) a little.

Notification when there's no match

Raise $Threshold in enter-client.ps1 (for example to 0.95) and restart the client.

"Client offline" on the page

Make sure the client window is still open and says Connected, and that the ID on the page matches the one in the window.

Start the client automatically with Windows

Press Win+R, type shell:startup, and put a shortcut to start.bat in the folder that opens.
